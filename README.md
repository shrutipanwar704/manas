Manas 🛍️ – Full Stack E-Commerce Website (MERN)

Manas is a fully responsive MERN stack e-commerce platform inspired by the GreatStack tutorial.
It includes a complete React frontend, Node/Express backend, MongoDB database, and a full Admin Panel for managing products, orders, and users.
Online payments supported using Stripe and Razorpay.

🔗 Live Link

👉 https://manas-2.onrender.com/

✨ Features

🚀 Installation
1️⃣ Clone the project
git clone https://github.com/shrutipanwar704/manas.git

cd manas

2️⃣ Install all dependencies

Frontend:

cd frontend
npm install


Backend:

cd backend
npm install


Admin Panel:

cd admin
npm install

3️⃣ Start Development Servers

Frontend:

npm start


Backend:

node server.js


Admin Panel:

npm start

📌 How the Project Works

User explores products, chooses variants, and places orders

Admin uploads and manages all store products

Backend handles all APIs (products, users, orders, payments)

Payments supported via Stripe 

MongoDB stores all users, products, orders, and admin data
